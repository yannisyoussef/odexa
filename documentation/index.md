Odexa is a distributed-commerce backend for catalog, inventory, checkout,
orders, provider-neutral payments, full financial refunds, and durable
integration events. The public edge is the normal client entry point; the
service contracts remain separate so ownership and trust boundaries stay
visible.

## Start here

- Bring up the [local stack](./local-quickstart).
- Understand [authentication and tenant isolation](./authentication).
- Walk through [multi-item checkout](./checkout).
- Browse the generated HTTP API reference for the gateway and each owning
  service.

<Callout type="warning" title="Development system">

Odexa is a working initial slice, not production-ready commerce. Read the
[known limitations](./limitations) before treating an endpoint or workflow as
a product commitment.

</Callout>
